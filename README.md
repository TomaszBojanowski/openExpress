# openExpress website

The page of [openExpress](https://github.com/TomaszBojanowski/openExpress) at
<https://openexpress.bojanowski.me>, served by GitHub Pages from this branch (`website`), which
shares no history with `main`. Plain HTML and CSS, no build; the screenshots are WebP, light and
dark, taken from the released version with no pictures of Garmin's devices.
